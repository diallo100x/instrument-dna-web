# Instrument DNA Web 0.5.6

Static browser prototype. Serve with `python3 -m http.server 8000`; open localhost:8000. Run model tests with `npm test`. No build or third-party runtime dependency. Main branch is deployed by the repository's existing GitHub Pages configuration, if enabled remotely.

## Current behavior

- Decode local audio, show waveform, track stable pitches through continuous phrases, retain each detected event for review and select up to 1/3/6/12 distinct anchors per octave. Three is the default target; missing recordings cannot be invented. Sustained and Plucked retain their existing segmentation. Struck / mallet detects short amplitude rises, splits repeated strikes even while a bar still rings, measures the pitched body after the hit, and retains the opening transient. Its pitch search reaches the high glockenspiel register. The chosen profile is stored in the preset and restored in the selector.
- The Detected note slices table lets users listen to each source slice, correct its MIDI key, or exclude speech and other wrong detections. Green keys show exact mapped recordings. Candidate slices beyond the capture density remain visible but are not mapped until the density or candidates change.
- For recordings longer than ten seconds, initially select the first ten seconds so speech at the end is excluded. Set Start/End (or the sliders), play the selection to confirm it contains only the desired instrument, then use Analyze selection & map. Select all restores the full recording. The source remains intact; clips are cut from the selected region, and the saved reflection includes absolute source timestamps and selection boundaries. Changing the selection clears the old map until it is analyzed again.
- Zoom in/out centers initially on the selected passage. After zooming, Move view pans through the recording; Fit full audio returns to the complete waveform. Shading tracks the crop as the viewport changes. Zoom and pan are display-only and do not modify source audio or anchor times.
- Preserve event measurements and individual anchor parameters, plus global and octave summaries. Estimate missing note parameters by interpolation between neighboring anchors and expose gap-based confidence and a suggested reference note.
- Play individually mapped slices in Raw and both Hybrid modes. The default Original Hybrid restores v0.4.2 exactly: recorded slices for mapped notes, and the harmonic oscillator model on every other note. It uses natural note length. Stretch Hybrid is experimental: for notes within four semitones of an anchor it uses waveform-matched grains with independent pitch and source progression; fixed 0.5/1/2-second note lengths also apply to Stretch and Reconstructed, including short MIDI taps. If rendering a clip fails, the voice falls back to the original recording or modeled oscillator. Raw requires an exact anchor and bypasses tone and Era processing. The entire earlier web build is preserved under `archive/v0.4.2/` for comparison.
- Capture density specifies the maximum **distinct recorded notes per octave**, not the number of notes that can be inferred from a recording. Changing Capture after analysis now immediately remaps candidates without rerunning the analyzer. The playable keyboard remains chromatic, with inferred keys clearly distinguished from recorded keys.
- DNA Reflections remain audio-free. The separate **playable comparison** download contains the selected anchor slices as lossless Float32 audio, model metadata and the chosen Hybrid mode. Loading it restores the sound comparison without needing to reload the source. Since it contains source-derived audio, retain it privately unless rights permit sharing.
- Detected slices can now be manually tagged as Sustain, Trill, Staccato, Accent, Breathy, or Alternate. The original Hybrid map is retained for backward comparison. Each articulation has its own sparse anchor map; tagged trill clips do not leak into the Sustain audition. A performance selector or optional high MIDI velocity switch (default threshold 100) chooses the trill layer. Recorded trills are pitch-adjusted within four semitones; farther pitches use a labeled generated harmonic trill with configurable rate and interval. Other articulations require recordings near the requested pitch; otherwise playback clearly reports a harmonic fallback. Articulation maps and performance options survive DNA Reflection save/load; playable comparisons additionally retain each layer's source slices. Old presets still load as their original single layer.
- Performance voice behavior can be set to Poly (previous overlapping playback), Mono (short one-voice handoff), or Legato (last held note priority, a short crossfade, and a pitch glide when transitioning between held notes). Releasing the latest key while holding another returns to the earlier key. Legato skips the start transient of recorded Hybrid clips, but retriggers a new recording and cannot reproduce an unrecorded continuous breath or slide. Raw stays an untouched slice and uses only the mono handoff. The mode and adjustable 10–250 ms glide persist in both preset formats; older presets load in Poly.
- For Struck / mallet, nearby notes in Stretch Hybrid retain the first 30 ms of the recorded strike before crossfading into the pitch-adjusted ringing body. Exact mapped keys still play the original clip. Original Hybrid keeps its previous behavior.
- Mallet · Velocity is a dedicated Struck audition map. Green keys use exact slices, amber keys transfer a nearby strike within five semitones, and gray keys farther from a recording use a finite modeled strike. The on-screen velocity control and MIDI velocity darken and soften low-velocity hits, reduce attack strength, and brighten and strengthen harder hits. Sampled notes ring after key release; the old Hybrid modes remain selectable. The modeled fallback is a conservative harmonic decay plus short excitation, not a measured vibraphone bar model. Existing playable comparisons retain their chosen mode, and a new save remembers Mallet mode.
- Model name initially follows the Instrument field (for example, “Pífano DNA Model”) and can be edited independently. Both preset types store the name and download with a safe filename derived from it; older unnamed presets receive a suggested name from their instrument classification. The editable Legato glide is synchronized before preset export.
- Save/load versioned JSON DNA Reflections containing source rights metadata, model hierarchy, confidence and unsupported-measurement markers. Source audio is never embedded. Edit global numeric offsets in Advanced, reset or compare original vs edited state. Main macros adjust attack, brightness and dynamics; XY Tone X affects brightness. The remaining macros and axes are stored for future mapping and currently do not change sound.
- Recording Era low-pass presets are separate from instrument data and adjustable in amount. They are illustrative effects, not historically measured models. MIDI input and keyboard audition are supported where the browser permits MIDI.

- Experimental Polyphonic notes profile uses onset detection and conservative spectral harmonic subtraction to propose up to four concurrent pitches per attack. Candidates share one source span and are individually reviewable, editable, and limited by the same per-octave capture density. Purple keys mark selected pitch anchors; gray keys are inferred. It saves pitch and onset measurements in an audio-free DNA Reflection with unsupported isolation and timbre fields explicitly marked. Listen plays the shared onset, not a separated note. Raw slices and playable comparison audio are unavailable for this profile; the model oscillator can audition the inferred pitches. Existing sustained, plucked and struck maps are unchanged.

## Boundaries and next steps

Polyphonic onset estimates can omit quiet chord tones, confuse harmonics, or assign pitches from multiple instruments. They do not separate individual notes or identify guitar timbre; the model-only sound is a generic oscillator. An actual polyphonic guitar performance requires ground-truth testing and a licensed source-separation or instrument-specific resynthesis stage before it can yield independently playable guitar timbres. Pitch segmentation in the original profiles assumes a clearly dominant monophonic pitch; music, speech, noise and overlapping instruments can yield plausible but false notes. Struck / mallet uses amplitude onsets rather than a trained instrument or mallet classifier; overlapping hits and strong room reflections still need manual review. Its decay parameter remains a bounded clip-length estimate, not a measured modal decay, and metallic partials may lead to octave errors that can be corrected in the slice table. Harmonic amplitudes are a preliminary short-window projection, with conservative confidence; spectral envelope, formant, resonance, noise-spectrum and nonlinear measurements remain unsupported. Granular looping may repeat a short source's vibrato and may blur attacks at larger shifts; it does not measure or reproduce a separate vibrato model. Generated trill fallback uses a chosen rate and interval rather than inferring either from the source. No trained historical presets or claims about archive rights. Sample slots and independent follow flags are schema only; no sample-driven resonator yet. A normal DNA Reflection contains no audio, so its reloaded Hybrid sound will use only the harmonic model. Next milestone: test the Struck / mallet profile on actual vibraphone, glockenspiel and xylophone recordings and measure their decay/resonance more accurately.

## Audio import formats

The file picker explicitly offers WAV, MP3, AAC/M4A/MP4, FLAC, Ogg Vorbis, Ogg Opus, uncompressed AIFF/AIFC, CAF and WebM. Browser-native decoding is attempted first. Lightweight, locally hosted decoders cover MP3, FLAC, Ogg Vorbis and Ogg Opus when native decoding fails; a PCM AIFF parser covers 8/16/24/32-bit AIFF and `sowt` AIFC. AAC/M4A, CAF and WebM require the browser to support the file's actual codec. Protected/DRM media, WMA and other proprietary or unusual codecs are not supported. Decode failures now report the format and keep a separate browser media preview available for troubleshooting. A preview that plays while instrument audition is silent points to the Web Audio path; silence in both suggests browser or system output configuration.

## Recognition research

`research/README.md` describes a separate, model-neutral evaluation workflow. It can compare the existing note detector with external tool outputs and human-reviewed labels without bundling their code, model weights, or source audio in the web product. No instrument-family classifier or automated recognition of “Pífano” is shipped yet.
